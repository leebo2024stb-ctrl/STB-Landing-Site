# 🚀 Azure Deployment in 30 Minutes - Quick Start Guide\n\n**This guide assumes:**\n- You have an Azure account (free tier works!)\n- You have the Azure CLI installed\n- Your GitHub repository is ready\n\n## ⏱️ Timeline\n- **Minutes 1-3:** Setup prerequisites\n- **Minutes 4-8:** Create Azure resources\n- **Minutes 9-18:** Deploy backend & database\n- **Minutes 19-27:** Deploy frontend\n- **Minutes 28-30:** Verify & celebrate! 🎉\n\n---\n\n## MINUTE 1-3: Prerequisites\n\n### Step 1: Install Azure CLI (if not already installed)\n\n**Windows (PowerShell as Admin):**\n```powershell\nwinget install Microsoft.AzureCLI\n```\n\n**macOS (Homebrew):**\n```bash\nbrew install azure-cli\n```\n\n**Linux (Ubuntu/Debian):**\n```bash\ncurl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash\n```\n\n### Step 2: Login to Azure\n\n```bash\naz login\n```\n\nThis opens your browser. Sign in with your Azure account, then return to terminal.\n\n### Step 3: Set Default Subscription\n\n```bash\n# List your subscriptions\naz account list --output table\n\n# Set the one you want to use\naz account set --subscription \"YOUR_SUBSCRIPTION_ID\"\n```\n\n✅ **Done with prerequisites!**\n\n---\n\n## MINUTE 4-8: Create Azure Resources\n\n### Step 4: Copy & Run Setup Script\n\nCreate a file called `azure-quick-deploy.sh` (or `.ps1` for PowerShell):\n\n**Bash (macOS/Linux):**\n```bash\n#!/bin/bash\nset -e\n\necho \"🚀 Creating Azure resources...\"\n\n# Variables\nRG=\"stb-app-rg\"\nLOCATION=\"eastus\"\nKV_NAME=\"stb-kv-$(date +%s)\"\nDB_SERVER=\"stb-db-$(date +%s)\"\nDB_ADMIN=\"sqladmin\"\nDB_PASSWORD=\"P@ssw0rd123456!\"  # Change this to something secure!\nAPI_APP=\"stb-api-$(date +%s)\"\n\n# 1. Create Resource Group\necho \"Creating resource group: $RG\"\naz group create --name \"$RG\" --location \"$LOCATION\"\n\n# 2. Create Key Vault\necho \"Creating Key Vault: $KV_NAME\"\naz keyvault create --name \"$KV_NAME\" --resource-group \"$RG\" --location \"$LOCATION\"\n\n# 3. Store secrets\necho \"Storing secrets in Key Vault...\"\naz keyvault secret set --vault-name \"$KV_NAME\" --name \"db-password\" --value \"$DB_PASSWORD\"\naz keyvault secret set --vault-name \"$KV_NAME\" --name \"jwt-secret\" --value \"dev-secret-key-change-in-production-min-32-chars-long-string\"\n\n# 4. Create SQL Server\necho \"Creating SQL Server: $DB_SERVER\"\naz sql server create \\\n  --name \"$DB_SERVER\" \\\n  --resource-group \"$RG\" \\\n  --location \"$LOCATION\" \\\n  --admin-user \"$DB_ADMIN\" \\\n  --admin-password \"$DB_PASSWORD\"\n\n# 5. Create SQL Database\necho \"Creating SQL Database...\"\naz sql db create \\\n  --name \"stb_applications\" \\\n  --server \"$DB_SERVER\" \\\n  --resource-group \"$RG\" \\\n  --service-objective \"S0\"  # Free tier\n\n# 6. Allow Azure Services to access database\necho \"Configuring firewall...\"\naz sql server firewall-rule create \\\n  --name \"AllowAzureServices\" \\\n  --server \"$DB_SERVER\" \\\n  --resource-group \"$RG\" \\\n  --start-ip-address \"0.0.0.0\" \\\n  --end-ip-address \"0.0.0.0\"\n\n# 7. Create App Service Plan\necho \"Creating App Service Plan...\"\naz appservice plan create \\\n  --name \"stb-api-plan\" \\\n  --resource-group \"$RG\" \\\n  --sku B2 \\\n  --is-linux\n\n# 8. Create App Service (Backend)\necho \"Creating App Service for backend...\"\naz webapp create \\\n  --name \"$API_APP\" \\\n  --resource-group \"$RG\" \\\n  --plan \"stb-api-plan\" \\\n  --runtime \"NODE|18-lts\"\n\necho \"\"\necho \"✅ Azure resources created!\"\necho \"Resource Group: $RG\"\necho \"Database Server: $DB_SERVER\"\necho \"App Service: $API_APP\"\necho \"Key Vault: $KV_NAME\"\necho \"\"\necho \"⚠️  SAVE THESE VALUES (you'll need them in next steps):\"\necho \"Database Server: $DB_SERVER.database.windows.net\"\necho \"Database Admin: $DB_ADMIN\"\necho \"Database Password: $DB_PASSWORD\"\necho \"JWT Secret: (saved in Key Vault)\"\necho \"\"\n```\n\n**PowerShell (Windows):**\n```powershell\n# Set variables\n$RG = \"stb-app-rg\"\n$LOCATION = \"eastus\"\n$KV_NAME = \"stb-kv-$(Get-Random)\"\n$DB_SERVER = \"stb-db-$(Get-Random)\"\n$DB_ADMIN = \"sqladmin\"\n$DB_PASSWORD = \"P@ssw0rd123456!\"\n$API_APP = \"stb-api-$(Get-Random)\"\n\n# Create resource group\nWrite-Host \"Creating resource group: $RG\"\naz group create --name \"$RG\" --location \"$LOCATION\"\n\n# Create Key Vault\nWrite-Host \"Creating Key Vault: $KV_NAME\"\naz keyvault create --name \"$KV_NAME\" --resource-group \"$RG\" --location \"$LOCATION\"\n\n# Store secrets\nWrite-Host \"Storing secrets...\"\naz keyvault secret set --vault-name \"$KV_NAME\" --name \"db-password\" --value \"$DB_PASSWORD\"\naz keyvault secret set --vault-name \"$KV_NAME\" --name \"jwt-secret\" --value \"dev-secret-key-change-in-production-min-32-chars-long-string\"\n\n# Continue with remaining commands...\n# (Same as bash version above)\n```\n\n### Step 5: Run the Script\n\n**Bash:**\n```bash\nchmod +x azure-quick-deploy.sh\n./azure-quick-deploy.sh\n```\n\n**PowerShell:**\n```powershell\nSet-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process\n.\\azure-quick-deploy.ps1\n```\n\n✅ **Azure resources created! Now save these values for next steps.**\n\n---\n\n## MINUTE 9-18: Deploy Backend & Database\n\n### Step 6: Configure Backend Environment Variables\n\n1. Open `.env.example` and copy to `backend/.env`\n2. Update with your Azure values:\n\n```env\nNODE_ENV=production\nPORT=8080\n\n# Database (from Azure resources created above)\nDB_HOST=stb-db-XXXXX.database.windows.net\nDB_PORT=1433\nDB_NAME=stb_applications\nDB_USER=sqladmin\nDB_PASSWORD=P@ssw0rd123456!\nDB_TYPE=mssql\nDB_ENCRYPT=true\n\n# JWT\nJWT_SECRET=dev-secret-key-change-in-production-min-32-chars-long-string\n\n# Azure Services (optional for now)\nAZURE_STORAGE_ACCOUNT_NAME=stbstorageprod\nFRONTEND_URL=https://your-domain.com\n```\n\n### Step 7: Deploy Backend Code\n\n```bash\ncd backend\n\n# Install production dependencies\nnpm install --production\n\n# Deploy to App Service\naz webapp deployment source config-local-git \\\n  --name \"stb-api-YOUR_APP_NAME\" \\\n  --resource-group \"stb-app-rg\"\n\n# Add Azure remote (copy the git URL from command above)\ngit add .\ngit commit -m \"Backend ready for Azure\"\ngit remote add azure <GIT_URL_FROM_ABOVE>\ngit push azure main\n```\n\n### Step 8: Configure App Service Settings\n\n```bash\naz webapp config appsettings set \\\n  --name \"stb-api-YOUR_APP_NAME\" \\\n  --resource-group \"stb-app-rg\" \\\n  --settings \\\n    NODE_ENV=production \\\n    PORT=8080 \\\n    DB_HOST=stb-db-XXXXX.database.windows.net \\\n    DB_NAME=stb_applications \\\n    DB_USER=sqladmin \\\n    DB_PASSWORD=P@ssw0rd123456! \\\n    JWT_SECRET=dev-secret-key-change-in-production-min-32-chars\n```\n\n### Step 9: Run Database Migrations\n\n```bash\n# From backend directory\nDB_HOST=stb-db-XXXXX.database.windows.net \\\nDB_NAME=stb_applications \\\nDB_USER=sqladmin \\\nDB_PASSWORD=P@ssw0rd123456! \\\nnpx sequelize db:migrate --env production\n```\n\n✅ **Backend deployed!**\n\n---\n\n## MINUTE 19-27: Deploy Frontend\n\n### Step 10: Create Static Web App\n\n```bash\n# First, get a GitHub personal access token\n# Go to: https://github.com/settings/tokens\n# Create new token with 'repo' and 'workflow' scopes\n# Copy the token\n\n# Then create the Static Web App\naz staticwebapp create \\\n  --name \"stb-frontend-prod\" \\\n  --resource-group \"stb-app-rg\" \\\n  --location \"eastus\" \\\n  --branch \"main\" \\\n  --repo-url \"https://github.com/leebo2024stb-ctrl/STB-Landing-Site\" \\\n  --repository-token \"YOUR_GITHUB_TOKEN_HERE\" \\\n  --app-location \"frontend\" \\\n  --output-location \"build\" \\\n  --app-build-command \"npm ci && npm run build\"\n```\n\n✅ **Frontend deployment started! It will auto-deploy on GitHub push.**\n\n### Step 11: Get Frontend URL\n\n```bash\naz staticwebapp show \\\n  --name \"stb-frontend-prod\" \\\n  --resource-group \"stb-app-rg\" \\\n  --query defaultHostname\n```\n\nThis is your frontend URL! It looks like: `https://xxx.azurestaticapps.net`\n\n### Step 12: Configure Frontend Environment\n\nUpdate `frontend/.env` or build configuration:\n\n```env\nREACT_APP_API_URL=https://stb-api-YOUR_APP_NAME.azurewebsites.net/api\n```\n\nThen commit and push:\n\n```bash\ncd frontend\ngit add .\ngit commit -m \"Configure API endpoint for Azure\"\ngit push origin main\n```\n\n---\n\n## MINUTE 28-30: Verify & Go Live! 🎉\n\n### Step 13: Test Your Deployment\n\n```bash\n# Test backend\ncurl https://stb-api-YOUR_APP_NAME.azurewebsites.net/health\n\n# Should return something like: {\"status\": \"ok\"}\n```\n\n### Step 14: Check Frontend\n\nOpen in browser:\n```\nhttps://stb-frontend-prod.azurestaticapps.net\n```\n\n### Step 15: View Logs (if something breaks)\n\n```bash\n# Backend logs\naz webapp log tail --name \"stb-api-YOUR_APP_NAME\" --resource-group \"stb-app-rg\"\n\n# Frontend logs\naz staticwebapp show --name \"stb-frontend-prod\" --resource-group \"stb-app-rg\"\n```\n\n---\n\n## 🎯 You Did It! Here's What You Have:\n\n✅ **Azure SQL Database** - Your data is stored securely  \n✅ **Node.js Backend** - Running on Azure App Service  \n✅ **React Frontend** - Deployed on Azure Static Web Apps  \n✅ **Automatic Deployment** - Push to GitHub → Auto-deploys  \n✅ **Key Vault** - Secrets managed securely  \n✅ **Free SSL Certificates** - HTTPS enabled automatically  \n\n---\n\n## 🚀 Next Steps (For Production)\n\n### Add Custom Domain\n\n```bash\n# Add domain to frontend\naz staticwebapp custom-domain register \\\n  --name \"stb-frontend-prod\" \\\n  --domain-name \"yourdomain.com\"\n\n# Add domain to backend\naz webapp config hostname add \\\n  --webapp-name \"stb-api-YOUR_APP_NAME\" \\\n  --resource-group \"stb-app-rg\" \\\n  --hostname \"api.yourdomain.com\"\n```\n\n### Enable Monitoring\n\n```bash\naz monitor app-insights component create \\\n  --app \"stb-insights\" \\\n  --location \"eastus\" \\\n  --resource-group \"stb-app-rg\" \\\n  --application-type web\n```\n\n### Setup CI/CD Pipeline\n\nGitHub Actions automatically triggers when you push:\n1. Deploys to Azure\n\nNo additional configuration needed!\n\n---\n\n## 💡 Troubleshooting Quick Reference\n\n| Issue | Solution |\n|-------|----------|\n| Database connection fails | Check firewall rule allows Azure Services |\n| Backend returns 502 | Check logs: `az webapp log tail --name stb-api-YOUR_APP_NAME` |\n| Frontend won't load | Check build logs in Azure Portal |\n| Git push fails | Ensure you have deployment credentials: `az webapp deployment user set` |\n| Can't login to Azure | Run `az login` again |\n\n---\n\n## 📞 Support Resources\n\n- [Azure CLI Documentation](https://learn.microsoft.com/cli/azure/)\n- [App Service Documentation](https://learn.microsoft.com/azure/app-service/)\n- [Static Web Apps Documentation](https://learn.microsoft.com/azure/static-web-apps/)\n- [Azure SQL Database](https://learn.microsoft.com/azure/azure-sql/)\n\n---\n\n## ✨ Congratulations!\n\nYou now have a **production-ready full-stack application** deployed on Azure!\n\n**Your application URLs:**\n- Frontend: `https://stb-frontend-prod.azurestaticapps.net`\n- Backend: `https://stb-api-YOUR_APP_NAME.azurewebsites.net`\n- Database: `stb-db-XXXXX.database.windows.net`\n\n🎉 **You're live!**\n"
